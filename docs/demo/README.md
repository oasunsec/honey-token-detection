# Local Word callback

[GIF preview](local-word-callback.gif) · [MP4 recording](local-word-callback.mp4)

Recorded on 7 September 2026 with desktop Word 16, a loopback FastAPI receiver, SQLite, and console alerts. The synthetic document generated a callback at `2026-09-07T21:03:31.811633+00:00`. Its stored user agent was `Mozilla/4.0 (compatible; ms-office; MSOffice 16)`; severity was `high` and console-alert status was `sent`.

The clip joins three captures from the same run: document creation through the CLI, the opened document in Word, and the stored event. The demo console displays selected live results; it is a recording aid, not an application dashboard. The file picker and pauses between captures were cut. The Word account area was cropped, mouse capture was disabled, and the cursor highlight stayed outside the frame. Callback tokens, addresses, personal paths, and account details are excluded.

This recording covers the local Word path. The separate Azure-to-Sentinel run is documented in the [case study](../../CASE_STUDY.md).
