# Screenshot evidence

The [numbered walkthrough](public/README.md) and [offline gallery](public/index.html) show the project from baseline through deployment, callback collection, triage, Sentinel ingestion, and tests. The package contains 17 images with source notes and hashes in [captions.json](public/captions.json).

Word and GitHub images are application captures. Azure images show saved API and query records rather than Azure portal screenshots. Sensitive identifiers are redacted or omitted; raw records remain outside the published package.

The final item records the remaining operational limits and teardown status.
